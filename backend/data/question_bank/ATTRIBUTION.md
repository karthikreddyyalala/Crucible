# Question bank attribution

Every question in this directory is written in our own words. Questions with
`"source": "original"` are wholly original. A question whose `source` is
`"adapted from <name>"` takes its topic or question stem from the work named
below; the wording, signal, ideal-answer points, weak-answer signs, follow-up
ladder and rubric descriptions are always original to this project.

Generic problem names (for example "design a URL shortener") are common ideas,
not anyone's expression, and are marked original.
